## Requirements

Nest Graph Inspector is built for modern NestJS applications and reads from the runtime Nest container after your app has initialized.

| Requirement | Version |
| ----------- | ------- |
| NestJS | 10 - 11 |

::callout{icon="i-lucide-lightbulb" color="neutral"}
Earlier NestJS versions may still work, but they are not officially supported. You can try force installing:

::package-manager-command{command="force-install"}
::

If it works for your project, [raise an issue](https://github.com/albasyir/nest-graph-inspector/issues) so support coverage can be updated.
::

## Browser

Any current browser can open the graph viewer. The AI chat is the one part that asks for more, because it runs its model on your own machine instead of on a server.

| Viewer feature | Browser requirement |
| -------------- | ------------------- |
| Graph, issue finder, Direct Run | Any current browser |
| AI chat | WebGPU — Chrome or Edge 113+, Safari 18+, or Firefox with WebGPU available |

The chat checks for WebGPU as soon as you open it, before you ask it anything, and says what is missing rather than failing mid-answer. Nothing else in the viewer depends on it, so a browser without WebGPU still shows the whole graph.

Choosing a model downloads it the first time. The browser caches it, so that cost is paid once per model and later sessions start with it already in place.

The model also has to fit in your GPU's memory while it answers. The six general models on offer need roughly 0.9 GB to 3.7 GB of VRAM, and the two tool-tuned Hermes builds need 3.9 GB and 4.8 GB. Each one says how much next to its name — a model that does not fit will download and then fail to load, so pick one your GPU has room for.
